# دروسنا — النسخة المحلية العاملة

منصة عربية RTL للمرحلة الثانوية: حسابات طالب وأدمن، اكتشاف المدرسين والكورسات، أكواد اشتراك من السنتر، فيديو وتقدم، واجبات وامتحانات، ودعم الطلاب. تعمل الآن بقاعدة البيانات المحلية وخدمات Auth؛ المحتوى والأسماء والصور والفيديوهات بيانات تجريبية.

## التشغيل على الجهاز الحالي

المتطلبات: Node.js 22.19 من سلسلة 22 وDocker Desktop. خدمات Supabase المحلية الأربع موجودة على الجهاز. بعد إعادة تشغيل الجهاز، افتح Docker وشغّلها من مجلد المشروع:

```powershell
.\experiments\auth-spike\scripts\start-local.ps1 -WithDataApi -ServerOnlyAuth -ProductMode
npm run dev
```

افتح [الموقع](http://127.0.0.1:3000) أو [دخول الأدمن](http://127.0.0.1:3000/login). الخادم يربط 127.0.0.1 فقط. للإيقاف استخدم Ctrl+C في طرفيته. لا تشغّل التطوير والنسخة المبنية معًا على المنفذ 3000. قبل `npm run build` أوقف التطوير؛ وبعد نجاح البناء شغّل `npm start`.

## تهيئة نسخة محلية جديدة

الإعدادات التالية محلية فقط وتحافظ على البيانات القائمة:

```powershell
npm ci
npm ci --prefix experiments/auth-spike
.\experiments\auth-spike\scripts\start-local.ps1 -WithDataApi -ServerOnlyAuth -ProductMode
npm run local:setup
npm run local:seed
npm run local:admin
npm install --prefix .local/media-tools @ffmpeg-installer/win32-x64@4.1.0 --no-audit --no-fund
npm run local:video
npm run dev
```

من طرفية ثانية، `npm run local:demo` يجهز وينشر دروس الكورسات التجريبية الثمانية فقط، عبر عمليات الأدمن الفعلية. لا تستخدمه لنشر محتوى المدرسين الحقيقيين. الفيديو الخاص في `.local/media/sample.mp4` وليس داخل `public`، وملف الخط وترخيصه داخل `src/fonts`.

`local:setup` يطبق ملفات migrations بالترتيب داخل `app_private` على اتصال localhost المتحقق منه، ويحفظ بصمت `.env.local`. يحفظ سجل التطبيق وبصمة كل ملف؛ لا يعيد تطبيقه ولا يمسح قاعدة موجودة. CLI 2.119.0 ترفض ملفات متعددة الأوامر في `db query`؛ يستخدم الإعداد اتصال PostgreSQL المحلي نفسه للمعاملة عند هذه الحالة المحددة. السجل المحلي مستقل عن تاريخ migrations الخاص بـSupabase؛ النقل إلى الاستضافة يحتاج إجراء مُراجع لاحقًا.

بيانات الأدمن مولدة ومحفوظة في `.local/admin-account.json` المستبعد من Git، وتُسلَّم لمالك المشروع في المحادثة. لا ترفع `.env.local` أو `.local` ولا تحفظ كلمات السر في ملفات التوثيق. `.env.example` يوضح أسماء المتغيرات فقط.

## الوظائف الحالية

- تسجيل ودخول برقم مصري وكلمة سر، مع جلسة تطبيق HttpOnly، وخروج وإلغاء الجلسات عند التعطيل والاستعادة. صلاحية الأدمن والحالة تُقرأ من قاعدة البيانات في كل عملية.
- تفعيل كود لكورس محدد 30/60/90 يومًا، تأكيد الاسم والمدة قبل التفعيل، تجديد، سجل وصول، سحب وتمديد إداري. بعد السحب يرجع الطالب بكود مختلف صالح إذا كان الحساب نشطًا والكورس منشورًا؛ الكود القديم لا يعيد الوصول.
- إدارة المدرسين والمواد والصفوف والكورسات والوحدات والدروس، وإصدارات الواجبات والامتحانات. النشر يحتاج جاهزية الفيديو والواجب؛ المسودات مخفية والأرشفة تحفظ الوصول السابق. المسودات غير المستخدمة تُحذف بمحتواها؛ العناصر المرتبطة بتاريخ تنتقل للمحذوفات مع زر استعادة وحفظ تقدم الطلاب ونتائجهم.
- واجبات وامتحانات مستقلة حسب الصف والمادة، تُنشر على `/assessments` ويحلها طالب نشط من نفس الصف دون اشتراك بكورس. النجاح فيها لا يفتح دروس الكورسات. تُدار من قسم التقييمات بالأدمن مع الأسئلة والإصدارات والمحاولات والنتائج.
- رفع صور المدرسين وأغلفة الكورسات من الجهاز، مع معاينة وتغيير وإزالة. JPG وPNG وWebP حتى ٥ ميجابايت و١٦ مليون بكسل؛ تُحفظ كـWebP محليًا داخل `.local/media/images` وتُعرض مباشرة من مسار الوسائط دون إعادة تشغيل الخادم. إزالة صورة من المحتوى لا تمسح أصلًا قد تستعمله مراجع أخرى؛ تظهر أيقونة مناسبة عند غياب الصورة.
- معالجة فيديو محلية تجريبية: معالجة/جاهز/فشل، وإعادة محاولة بجيل جديد. أجيال قديمة لا تعلن جاهزية البديل. تشغيل خاص مع طلبات Range، حفظ آخر موضع، ومشاهدة واحدة لكل طالب قابلة للنقل بين الأجهزة.
- زر إكمال مستقل عن نسبة المشاهدة. الدرس التالي يحتاج إكمال السابق ونجاح واجبه من 70% بالدرجات الموزونة؛ المحاولات غير محدودة وأول نجاح محفوظ. الاستثناء الإداري لدرس محدد لا يتجاوز الحساب أو الاشتراك.
- امتحان بوقت ومحاولات وإصدار ثابت لكل محاولة. إجابات تُحفظ بإصدارات؛ الواجهة تفرّق بين «على الجهاز فقط» و«محفوظ في السيرفر». التصحيح يحسب ما وصل للسيرفر، والوقت يستمر دون اتصال.
- تسليم تلقائي للامتحانات عبر عامل محلي كل خمس ثوانٍ، حتى مع إغلاق المتصفح أو سحب الوصول أو تعطيل الطالب. العامل يحتاج بقاء خادم الموقع وقاعدة البيانات شغالين؛ يعالج المتأخر عند تشغيله من جديد.
- الدرجة فور التسليم؛ نموذج الامتحان بعد موعد الإغلاق، أو استنفاد محاولات الطالب عندما لا يوجد إغلاق. نموذج النتيجة مرتبط بإصدارها القديم ولا يختفي بتغيير الإصدار التالي.
- استعادة حضورية: كود 15 دقيقة لمرة واحدة، الطالب يختار كلمة سر بنفسه، مع إبطال الجلسات القديمة وحفظ التقدم. الاستعادة لا تنشّط حسابًا معطّلًا. الأدمن يراجع التسجيل أو الاستعادة غير المكتملة دون تخمين نجاح خدمة Auth.
- سجل آخر 100 إجراء للأدمن، يتضمن الفاعل والوقت والسبب؛ أسرار الأكواد وكلمات السر وتوكنات Auth لا تدخل السجل.
- لوحة إدارة بقائمة جانبية على اليمين، مع تمييز القسم الحالي وتجميع المحتوى والاشتراكات والإعدادات. خط Cairo محلي وأسماء أوضح وكروت كورسات بنسبة ١٦:٩، ووضع فاتح/داكن موحد محفوظ على الموقع كله. القائمة تفتح بزر على الموبايل والجداول تتحول إلى بطاقات. التفاصيل في [مراجعة لوحة الإدارة](docs/phase-2/F13-admin-sidebar.ar.md) و[مراجعة الكروت والثيم](docs/phase-2/F14-public-theme-cards.ar.md).

## التحقق

```powershell
npm run lint
npm run typecheck
npm run build
npm start
# من طرفية ثانية، للتجربة المحلية وبيانات الاختبار فقط:
npm run test:local
# التغييرات الأخيرة، باستخدام بيانات تحقق مستقلة:
node scripts/verify-local-media.mjs
node scripts/verify-local-deletion.mjs
node scripts/verify-local-standalone.mjs
```

الاختبارات تمر عبر HTTP وقراءة قاعدة البيانات للتحقق من النتائج؛ تنشئ حسابات ومواد وكورسات تجريبية وتحفظ تاريخها. لا تشغّلها على بيانات إنتاج. محاكاة انتهاء كود الاستعادة والانقطاع قبل الإنهاء تستخدم تعديلات محدودة على سجل حساب الاختبار فقط. التقارير الخام مستبعدة من Git داخل `.local/f06-auth-result.json` حتى `.local/f12-browser-result.json`؛ التقرير المنقح في `docs/phase-2/F06-F12-local-platform.ar.md`.

## ما قبل الإتاحة الحقيقية

اسم المنصة والألوان والصور والمحتوى تحتاج مراجعة المالك. الفيديو المحلي يختبر تدفق التطبيق فقط؛ ربط Bunny الفعلي ورفع ملفات المدرسين واختبار الشبكات والتكلفة والاستضافة والدومين وإعدادات التشغيل والحماية والنسخ الاحتياطي واستمرارية عامل الامتحانات تُنجز قبل الإطلاق، وفق اتفاق تأجيلها. لا خدمة مدفوعة أو رفع نهائي تم في هذه الدفعة.

قواعد المنتج في [سجل القرارات](docs/phase-1/decisions.ar.md)، والمرجع البصري في [نظام التصميم](design-system/dorosna-mvp/MASTER.md). أحدث موافقة من المالك تعتمد لوحة الإدارة وتجيز إكمال الدارك مود العام والكروت والصور والتقييمات المستقلة والحذف مع المراجعة دون توقف إلا لقرار مهم. هذه الدفعة محلية ولم تنشر الموقع. الصور والبيانات المضافة محليًا تحتاج النقل ضمن إجراء الاستضافة والنسخ الاحتياطي قبل الإطلاق.
