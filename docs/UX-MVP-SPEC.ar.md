# مواصفات UI/UX للنسخة الأولى — منصة تعليمية مصرية

> اسم العمل داخل التصميم: **دروسنا**. الاسم مؤقت حتى اعتماده.  
> الجمهور: طلاب الثانوية في مصر.  
> النطاق: تجربة الطالب + لوحة إدارة MVP، من دون حسابات مدرسين.

## قرار المنتج الأساسي

الواجهة الرئيسية بعد تسجيل الدخول هي لوحة وصول سريعة، وليست صفحة تسويق. أعلى الشاشة يعرض الكورس الجاري وإجراء «كمّل الدرس»، ثم المدرسين والكورسات المقترحة. تفعيل الكود متاح من الرئيسية ومن صفحة الكورس، لكنه يظهر بوضوح أكبر في صفحة الكورس حتى يبقى معنى الكود مرتبطًا بما سيفتحه.

## التدفقات الحرجة

### 1. طالب جديد يكتشف ويفعّل كورسًا

`الرئيسية ← المدرسون ← المدرس ← الكورس ← أدخل الكود ← نجاح التفعيل ← ابدأ أول درس`

- صفحة المدرس تعرض المادة والصفوف والكورسات مباشرة.
- تفاصيل الكورس تعرض الغلاف، المدرس، الصف، المدة الشهرية، وعدد الدروس.
- حقل التفعيل فوق قائمة المحتوى على الهاتف، مع إمكانية معاينة عناوين الوحدات دون تشغيلها.
- نجاح التفعيل يحدّث CTA في نفس السياق إلى «ابدأ أول درس» ولا يجبر الطالب على البحث عن الكورس ثانية.

### 2. طالب يعود ليكمل

`الرئيسية ← كمّل من حيث توقفت ← مشغل الكورس عند آخر موضع`

- يُحفظ موضع الفيديو.
- يظهر ما يلزم لفتح الدرس التالي بجوار تقدم الدرس الحالي.
- عند ضعف الاتصال، يمكن اختيار جودة أقل وتظهر حالة الحفظ.

### 3. واجب يفتح الدرس التالي

`الدرس ← ابدأ الواجب ← أجب ← راجع ← سلّم ← نتيجة الواجب ← فتح الدرس التالي`

- رأس ثابت خفيف: رقم السؤال والتقدم.
- زر «التالي» لا يتقدم قبل اختيار إجابة، مع رسالة بجوار السؤال.
- بعد التسليم تظهر الدرجة وعبارة صريحة: «تم فتح الدرس 4» أو «أعد المحاولة لفتح الدرس» وفق السياسة.

### 4. امتحان وتصحيح تلقائي

`صفحة الكورس ← ابدأ الامتحان ← تعليمات قصيرة ← الأسئلة ← تأكيد التسليم ← النتيجة`

- الحفظ التلقائي وحالة «تم الحفظ الآن» ظاهرة.
- التنقل بين الأسئلة ممكن من خريطة الأسئلة، مع تمييز مجاب/غير مجاب بالنص والشكل.
- النتيجة: الدرجة، النسبة، النجاح/يحتاج مراجعة، ثم ملخص صحيح/خطأ/غير مجاب.

### 5. الأدمن ينشئ كورسًا جاهزًا للبيع

`كورس جديد ← البيانات والغلاف ← الوحدات ← الدروس والفيديو ← واجبات الفتح ← امتحان ← نشر ← توليد دفعة أكواد`

- الإنشاء يستخدم خطوات واضحة مع حفظ كمسودة.
- لا يتطلب وجود حساب للمدرس؛ يُختار المدرس من سجل يديره الأدمن.
- دفعة الأكواد تحدد الكورس والمدة والعدد، ثم تُصدر CSV للطباعة/التوزيع.

## مواصفات الشاشات الرئيسية

### الرئيسية — الطالب

ترتيب المحتوى:

1. App bar: اسم المنصة، بحث، صورة الطالب.
2. إن وجد كورس جارٍ: بطاقة «كمّل» بعرض الشاشة مع التقدم واسم الدرس.
3. اختصارات: فعّل كود، كورساتي، المدرسون.
4. «مدرسين ليك» في صف كروت لا يزيد على 4 قبل «عرض الكل».
5. «كورسات مناسبة لصفك».
6. الشريط السفلي.

النسخة الجديدة بلا اشتراكات تستبدل بطاقة المتابعة بدعوة صغيرة: «معاك كود كورس؟ فعّله دلوقتي».

### المدرسون

- عنوان + بحث مباشر + chips للمادة والصف.
- Grid صورتان في الصف على 390px، مع الحفاظ على هدف لمس الكرت كاملًا.
- الفلاتر الإضافية في bottom sheet، ولا تظهر لوحة فلاتر ضخمة.

### صفحة المدرس

- بطاقة هوية قصيرة: صورة، اسم، مادة، صفوف.
- تبويب افتراضي «الكورسات»؛ النبذة اختيارية ومطوية.
- كورسات المدرس مرتبة: كورسات صف الطالب أولًا.

### تفاصيل الكورس والتفعيل

الترتيب الموصى به:

1. الغلاف + عنوان الكورس.
2. المدرس، الصف، عدد الدروس، مدة الوصول.
3. CTA «فعّل بالكود» مثبت أسفل الهاتف.
4. «هتتعلم إيه؟» في 3 نقاط كحد أقصى.
5. محتوى الكورس: أسماء الوحدات والدروس مع أقفال.
6. سياسة الوصول والأسئلة الشائعة المختصرة.

التفعيل يظهر bottom sheet فيه label «كود الاشتراك»، helper يوضح مكان الكود، CTA واحد، وحالات: جارٍ التحقق، غير صحيح، مستخدم، منتهي، أو نجاح.

### كورساتي

- أول كرت للكورس الأخير مع CTA «كمّل».
- فلاتر صغيرة: الكل، نشط، منتهي.
- الكورس المنتهي يبقى مرئيًا مع «فعّل كودًا جديدًا» ولا يختفي.

### مشغل الكورس

- فيديو بنسبة 16:9 مع عنوان الدرس وحالة الحفظ.
- شريط تقدم الكورس منفصل عن تقدم الفيديو.
- CTA سياقي تحت الفيديو: «حل الواجب» أو «الدرس التالي».
- قائمة الدروس تحمل سبب القفل، ولا تستخدم قفلًا صامتًا.

### الواجب

- سؤال واحد في الشاشة على الهاتف لتقليل الحمل البصري.
- التقدم «3 من 10» وشريط بسيط.
- زر رجوع يحفظ الإجابة، وزر التالي لا يرسل الواجب.
- شاشة مراجعة تعرض غير المجاب قبل التسليم.

### الامتحان والنتيجة

- الامتحان يضيف مؤقتًا وخريطة أسئلة وحفظًا تلقائيًا.
- النتيجة تعطي معنى قبل التفاصيل: «نجحت» أو «راجع الجزئية دي»، الدرجة، ثم الإحصاءات.
- مشاركة النتيجة خارج نطاق MVP ما لم تُعتمد لاحقًا.

## لوحة الإدارة

### نظرة عامة

- أرقام تشغيلية فقط: طلاب نشطون، اشتراكات نشطة، تفعيلات اليوم، كورسات منشورة.
- نشاط حديث وأخطاء تحتاج تدخلًا مثل فيديو غير متاح أو دفعة أكواد قاربت على النفاد.
- لا تُملأ الصفحة برسوم بيانية لا تقود إلى قرار.

### المدرسون

- جدول desktop وبطاقات mobile: الصورة، الاسم، المادة، عدد الكورسات، الحالة.
- النموذج: الاسم، الصورة، المادة، الصفوف، نبذة قصيرة، حالة النشر.

### الكورسات والمنهج

- حالات واضحة: مسودة، جاهز للمراجعة، منشور، مؤرشف.
- منشئ المنهج يدعم إضافة وحدة ودرس، وترتيبًا بأزرار أعلى/أسفل كبديل للـ drag.
- لكل درس: عنوان، فيديو، مدة، preview، واجب فتح، وحالة النشر.

### الأكواد

- إنشاء دفعة: الاسم الداخلي، الكورس، مدة الوصول 30 يومًا افتراضيًا، العدد، تاريخ انتهاء صلاحية التفعيل إن وجد.
- تفاصيل الدفعة: إجمالي، متاح، مستخدم، ملغى، مع بحث بالكود وتصدير CSV.
- إلغاء كود إجراء destructive بتأكيد يعرض الكود والكورس.

### الواجبات والامتحانات

- محرر سؤال: نص، 2–6 اختيارات، إجابة صحيحة واحدة، شرح اختياري، درجة.
- preview مطابق لتجربة الطالب.
- إعدادات: حد النجاح، عدد المحاولات، ترتيب عشوائي، إظهار الإجابات بعد التسليم.

## حالات البيانات والرسائل

| الحالة | الرسالة الأساسية | الإجراء |
|---|---|---|
| لا توجد كورسات | «لسه مفعّلتش أي كورس» | «فعّل كود» |
| لا نتائج مدرسين | «مفيش مدرسين مطابقين للفلاتر» | «امسح الفلاتر» |
| كود غير صحيح | «راجع الكود وحاول تاني» | إبقاء الحقل والقيمة |
| كود مستخدم | «الكود اتفعّل قبل كده» | «تواصل مع الدعم» |
| اشتراك منتهي | «انتهى وصولك للكورس» | «فعّل كودًا جديدًا» |
| درس مقفول | «حل واجب الدرس السابق علشان تفتحه» | «اذهب للواجب» |
| انقطاع أثناء امتحان | «الإجابات محفوظة على الجهاز» | «إعادة الاتصال» |
| فشل الفيديو | «تعذر تشغيل الفيديو» | «أعد المحاولة» + جودة أقل |

## مواصفات التنفيذ

- الاتجاه `dir="rtl"` من الجذر، مع استخدام logical properties مثل inline-start/end.
- الصور: AVIF/WebP، lazy loading لما تحت fold، وأبعاد ثابتة.
- فيديو: adaptive streaming، اختيار الجودة، استكمال الموضع، وحالة offline واضحة.
- التنقل: deep links للكورس والدرس، وBack يعيد الفلاتر وموضع التمرير.
- الوصول: semantic headings، labels، keyboard، focus، alt، live region لحالة الحفظ والتفعيل.
- الأمان المرئي: لا يظهر الكود كاملًا بعد الاستخدام في سجل الطالب؛ يعرض آخر 4 أحرف فقط.
- الاختبارات: حفظ تلقائي عند كل انتقال وبعد فترة قصيرة، مع idempotent submit لمنع تكرار التسليم.
- التحليلات المقترحة: `course_viewed`، `code_activation_started`، `code_activated`، `lesson_started`، `lesson_completed`، `homework_submitted`، `exam_submitted`.

## القرارات المفتوحة للمراجعة

1. **الاسم:** «دروسنا» اسم عمل؛ بدائل الاتجاه: «حصتك»، «مذاكر»، «دَرْسَك».
2. **الألوان:** الموصى به تركواز هادئ؛ البدائل أزرق أكاديمي أو بنفسجي شبابي.
3. **الكروت:** الموصى به صورة كبيرة + حدود خفيفة؛ البديل كرت أكثر كثافة بمعلومات ظاهرة.
4. **الكثافة:** الموصى بها متوسطة للطالب، وعالية محسوبة في جداول الأدمن.
5. **صفحة الكورس:** الموصى به التفعيل أولًا مع معاينة المحتوى؛ البدائل المحتوى أولًا أو المدرس أولًا.

هذه القرارات لا تغيّر بنية التدفقات، لكنها تغيّر الهوية والتسلسل البصري، لذلك يجب اعتمادها قبل مرحلة الـ high fidelity النهائية.
