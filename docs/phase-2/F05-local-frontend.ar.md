# F05 — أول واجهة عربية عاملة محليًا

2026-10-02. أُنجزت دفعة الفرونت التي وافق عليها المستخدم برسالة «ابداء»: إعداد المشروع والواجهة والتنقل وصفحات الحساب والتصفح ببيانات تجريبية. [افتح المعاينة المحلية](http://127.0.0.1:3000/)؛ [تعليمات التشغيل](../../README.ar.md)؛ [النتائج التفصيلية](F05-validation-result.json).

## الناتج

التطبيق في `src/app` و`src/components`، باستخدام Next.js 16.3.8 وReact 19.3.0 وTypeScript. الاعتماديات مثبتة في `package-lock.json`. `npm run dev` و`npm start` يربطان الخادم بـ127.0.0.1:3000 فقط. الخط العربي والرسوم SVG محلية، ولا يحتاج تشغيل هذه الواجهة Supabase أو Docker أو مفاتيح أو خدمة مدفوعة.

| الصفحات | السلوك المتاح |
|---|---|
| `/` | رئيسية لزائر، اكتشاف المواد والمدرسين والكورسات وبحث سريع |
| `/teachers` و`/teachers/[slug]` | 4 مدرسين تجريبيين، بحث عربي وفلاتر مادة وصف، نبذة وكورسات المدرس |
| `/courses` و`/courses/[slug]` | 8 كورسات تجريبية، بحث وفلاتر، بيانات الكورس والوحدات والدروس وسياسة الوصول |
| `/login` و`/register` | واجهة هاتف وكلمة سر؛ التسجيل يضيف الاسم والصف. أخطاء مرتبطة بالحقول وملخص يركز عليه المتصفح، إظهار كلمة السر، ورسالة معاينة صريحة |
| `/my-courses` و`/account` | حالة زائر واضحة وروابط للحساب والتصفح، دون اختلاق اشتراكات أو نتائج |
| `/help` | إرشاد الاشتراك بالكود واستعادة الحساب بعد تحقق حضوري في السنتر |

الفلاتر تستخدم GET عبر Next Form وتبقى في رابط الصفحة، بما يحفظ سياق الرجوع من التفاصيل. القوائم العامة وتفاصيلها Server Components تعتمد فقط على `src/lib/catalog.ts`. لا API أو قاعدة بيانات خلف القوائم في F05. روابط التفاصيل غير المعروفة ترجع 404؛ `dynamicParams=false` مناسب للقائمة التجريبية الثابتة ويُراجع عند ربط بيانات النشر.

التصميم يستند إلى [نظام التصميم](../../design-system/dorosna-mvp/MASTER.md): RTL، لون أخضر هادئ، صور وبطاقات بمساحات ثابتة، تنقل سفلي بأربعة عناصر على الهاتف، وتنسيق للتابلت والكمبيوتر. رسوم المدرسين والأغلفة أصلية للتجربة بدل صور أشخاص حقيقيين؛ الاسم والصور النهائية ما زالت مؤجلة وفق D22. لا ادعاء بمطابقة Figma بكسلًا ببكسل أو اعتماد الهوية النهائية.

بحث مهارة UI/UX المحلي عن فلاتر query string لم يعطِ مطابقة موثقة؛ تنفيذ الفلاتر يستند إلى دليل Next Form الموجود في `node_modules/next/dist/docs` وقواعد النظام المحلي، دون اعتماد نتيجة بحث غير مناسبة.

## حدود الحسابات والتعلّم

نماذج الحسابات تراجع شكل البيانات فقط. عند بيانات صحيحة تعرض أن الدخول أو إنشاء الحساب غير متاح في المعاينة، وتمسح حقل كلمة السر. المصدر لا يرسل بيانات النموذج أو يحفظها في تخزين المتصفح؛ ولم يرصد مسجل طلبات الاختبار POST بعد التسليم الصحيح للنموذجين. لا حساب أو جلسة أو اشتراك أُنشئ بهذه الواجهة.

رابط العودة بين نموذجَي الحساب يقبل كورسًا معروفًا محليًا فقط. تظل الأزرار وروابط الرجوع قابلة للتجربة دون ادعاء تسجيل الدخول. لا حساب مدرس أو بريد أو SMS. إرشاد الاستعادة ليس تنفيذًا لعملية الاستعادة.

عناوين الدروس للمعاينة فقط، مع أقفال وأسبابها؛ فتح وإغلاق الوحدات يعمل. لا فيديو أو واجب أو امتحان أو تفعيل كود في هذه الدفعة. النصوص تتبع القرارات الأحدث: الإكمال بزر مستقل، واجب بنسبة 70٪ ومحاولات غير محدودة، ومدد أكواد 30/60/90 يومًا؛ نص MASTER الأقدم عن نسبة مشاهدة إلزامية لا يُطبق.

## التحقق المنجز

- نجحت `npm run build` و`npm run lint` و`npm run typecheck` بعد التعديلات الأخيرة.
- فحص HTTP لـ20 صفحة فعلية: كلها 200، عربية RTL وبعنوان h1 واحد. وثلاثة روابط غير موجودة عرضت شاشة المشروع ورجعت 404. مجموع حالات HTTP: 23.
- 30 حالة عرض: خمس صفحات (الرئيسية، المدرسون، تفاصيل كورس، التسجيل، الدخول) × ستة مقاسات: 375×812 و390×844 و768×1024 و1024×768 و1440×1000 و844×390. لا تمرير أفقي أو overlay خطأ، وRTL موجود في جميعها.
- اختُبرت رحلة الرئيسية←الكورسات←فلترة الفيزياء/الثالث←تفاصيل الكورس←رجوع؛ بقيت الفلاتر ونتيجة واحدة. البحث بلا نتائج أعطى حالة مفهومة، والبحث «احمد» وجد «أحمد حسن».
- اختُبر تنقل الهاتف، فتح الوحدة الثانية، وروابط الكورس←الدخول مع حفظ سياق الكورس. في التسجيل الناقص ظهرت أربعة أخطاء، وفي الدخول الناقص خطآن؛ انتقل التركيز لملخص الأخطاء. رقم عربي في التسجيل ورقم +20 في الدخول اجتازا مراجعة الشكل، وعُرضت رسالة المعاينة دون طلب POST.
- فحص axe-core 4.12.1 على الرئيسية والكورسات والمدرسين وتفاصيل الكورس والتسجيل والدخول: صفر مخالفات في اللقطات النهائية. الرئيسية احتاجت مراجعة يدوية لأربعة رموز مواد زخرفية؛ نسب التباين المحسوبة من الألوان الفعلية 6.81 و6.54 و5.22 و6.00، وكلها فوق 4.5. هذا فحص آلي محدد مع مراجعة هذه الرموز، وليس شهادة امتثال كاملة.
- شوهدت لقطات الكمبيوتر والهاتف، وحُسن ترتيب تفاصيل الكورس على الهاتف ليظهر العنوان والمدرس قبل بطاقة الاشتراك. التركيز على حقل البحث ظهر أعلى الشريط السفلي.

أداة المتصفح داخل التطبيق لم تبدأ بسبب خطأ تجهيز محلي (`failed to write kernel assets`)، فاستُخدمت أداة agent-browser 0.38.2 مع Edge في الخلفية وسياق منفصل، دون قراءة ملف المستخدم أو كوكيز أو تخزين متصفحه. أُغلق سياق الاختبار وبقي خادم المعاينة شغالًا. طلب فتح المعاينة داخل Codex أعاد `queued`؛ لا ادعاء بأن التبويب ظهر في النافذة الحالية.

عند تغيير إعداد 404 أثناء التطوير، احتفظ خادم التطوير بإجابة قديمة لمسار مدرس؛ أُعيد تشغيل عملية F05 التي تأكد مسارها ومنفذها فقط، ثم نجح فحص 404. لم تُوقف خدمات تجربة Supabase أو Docker.

بوابات الإطلاق الأوسع ما زالت في الخطة: تكبير المتصفح 200٪ على أجهزة فعلية، مراجعة قارئ شاشة فعلية، جميع حالات الشبكة والبيانات المحمية ورحلات التعلم والإدارة والفيديو الحقيقي. نتائج F05 لا تثبت هذه الرحلات.
