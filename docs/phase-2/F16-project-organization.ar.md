# F16 — تنظيم المشروع قبل تجهيز النسخة الأونلاين

تاريخ العمل: 3–4 أكتوبر 2026. اكتمل تنظيم الملفات والتحقق المحلي. اعتمد المالك التصميم الجديد بعد مراجعة المعاينة؛ تنفيذه وتجهيز مشروع Supabase المؤكد موثقان في [F17](F17-student-design-cloud-readiness.ar.md).

## التقسيمة

- `src/app`: صفحات الموقع وواجهات API ومساراتها الحالية.
- `src/components`: مكونات مقسمة إلى `common` و`catalog` و`admin` و`auth` و`enrollments` و`learning` و`assessments`.
- `src/server`: خدمات مقسمة إلى `core` و`auth` و`catalog` و`enrollments` و`assessments` و`learning` و`media` و`jobs`.
- `src/lib`: الأدوات الصغيرة المشتركة مثل الوقت والمدخلات والثيم.
- `scripts/local`: تجهيز وتشغيل البيانات والخدمات المحلية.
- `scripts/verification`: اختبارات الوظائف عبر HTTP وقاعدة البيانات.
- `scripts/shared`: تحديد جذر المشروع ومكان الخدمات المحلية الحالي.
- `docs/engineering`: شرح الهيكل وأوامر العمل.
- `docs/deployment`: متطلبات المالك وخطة ربط النسخة التجريبية بالأونلاين.
- `docs/research`: مراجعة روابط الأدوات الخارجية ومتى تفيد المشروع.

نُقل ٤٣ ملفًا من كود التطبيق، وتحدّث ٢٣١ مرجع import في ٦٨ ملفًا. النقل يحافظ على حدود مكونات الخادم والعميل، والخطوط وملفات CSS ومسارات صفحات الموقع. لا تغيير في قواعد الاشتراك أو النتائج أو حذف المحتوى بسبب تنظيم الملفات.

أُزيل اعتماد Noto غير المستخدم من dependencies والـlock، وحُفظت تراخيص الخطوط. أصبح أمر `test:features` يجمع اختبارات الصور والحذف والتقييمات المستقلة، وأصبح `format:check` متاحًا لمراجعة التنسيق. بيانات Docker ومجلد تجربة Auth باقية في موقعها؛ واجهة التشغيل الجديدة تشير إلى مكانها الحالي.

## الملفات المحلية وGit

تظل ملفات الحسابات والأسرار والفيديوهات والصور المرفوعة وتقارير التحقق والمعاينة داخل `.local` وخارج Git. أُضيف استبعاد ملفات ربط Netlify وVercel وملفات Supabase المؤقتة. ملف `supabase/.temp/cli-latest` خرج من التتبع؛ نسخته المحلية باقية.

تعديلات التوثيق التي كانت موجودة قبل هذه المرحلة محفوظة. لم يُنفذ commit أو push أو نشر سحابي في هذه المرحلة.

## التحقق

نجحت فحوص `format:check` و`lint` دون تحذيرات و`typecheck` و`build`، ثم شُغلت النسخة المبنية وفُحصت عبر HTTP وقاعدة البيانات. المراجعة النهائية استخدمت Node 22.19.0؛ قُدّم مساره في PATH حتى لا تختار الأدوات نسخة Node 24 المرفقة ببيئة المساعد.

| المجموعة                              | عدد الفحوص الناجحة في الجولة الأخيرة |
| ------------------------------------- | ------------------------------------ |
| الحسابات والجلسات                     | 12                                   |
| الأكواد والاشتراكات                   | 12                                   |
| الفيديو والتقدم والواجب ووقت الامتحان | 20                                   |
| الاستعادة وإصلاح التسجيل غير المكتمل  | 11                                   |
| إدارة المحتوى والنشر والأرشفة         | 13                                   |
| رفع الصور وتبديلها وإزالتها           | 12                                   |
| الحذف والاستعادة وحفظ التاريخ         | 13                                   |
| الواجبات والامتحانات المستقلة         | 15                                   |
| **الإجمالي**                          | **108**                              |

`test:local` نجح بـ68 فحصًا، و`test:features` نجح بـ40 فحصًا. لم تُحسب الجولات السابقة ضمن الإجمالي. فحص مستقل قارن بنية 98 ملفًا قبل نقل المصدر وبعده، وأكد أن تغييرات المصدر اقتصرت على مراجع الاستيراد؛ التنسيق لا يغير منطق التطبيق.

ظهرت مشكلتان في الاختبارات القديمة وحُلتا: فحص الأكواد كان يفترض نشر كورس العرض `physics-electricity` رغم أنه أصبح مسودة؛ صار ينشئ كورسًا مستقلًا عبر عمليات الأدمن ويخفي بيانات جولته بعد الاختبار مع حفظ التاريخ. وفحص الإدارة كان يقارن كائني Date بالهوية؛ صار يقرأ `timestamptz` كنص كما يفعل الخادم، لحفظ دقة التاريخ ومقارنة القيمة. لا تعديل في كورس العرض أو سلوك الإنتاج لحل هاتين المشكلتين.

المعاينة التفاعلية محفوظة خارج كود التطبيق في `.local/design-proposals/student-refresh-v2`. راجعت في المتصفح البحث والفلاتر وعدم وجود نتائج ومسح الاختيارات وفتح التفاصيل وإغلاقها والدارك بعد إعادة التحميل وعرض الطالب التجريبي. إطار معاينة الموبايل بعرض 412px لا يظهر تمريرًا أفقيًا، وحقل البحث فيه 16px. هذه مراجعة للإطار داخل متصفح الكمبيوتر، وليست ادعاءً بتجربة جهاز موبايل فعلي. نجح أيضًا فحص ثابت لـ46 زوج ألوان؛ أقل تباين للنصوص العادية 5.3:1 ضمن الأزواج المقاسة.

لقطات الكمبيوتر والفاتح والدارك والكروت والموبايل وتقرير المتصفح محفوظة مع المعاينة. اعتمد المالك التصميم بعدها، وطُبق على صفحات الموقع الفعلية في F17.
