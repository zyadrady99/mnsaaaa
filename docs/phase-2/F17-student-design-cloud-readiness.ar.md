# F17 — التصميم المعتمد وتجهيز الربط السحابي

تاريخ المراجعة: ٤ أكتوبر ٢٠٢٦. اعتمد المالك الشكل الجديد وتنفيذه، واختار Netlify وبيانات تجريبية، وأكد مشروع Supabase ثم وافق صراحة على تطبيق ملفات قاعدة البيانات الأربعة عليه.

## الواجهة الفعلية

طُبق الشكل في `src/app/page.tsx` ومكونات الكتالوج و`student-design.css`، ببيانات منشورة من قاعدة البيانات الحالية. تغيرت الرئيسية والكروت والفلاتر وكورساتي، مع Cairo محلي وأسماء مدرسين بوزن 800 وصور كورسات بنسبة 16:9. البحث في الرئيسية مباشر ويحفظ الصف والمادة والكلمة في URL؛ صفحة الكورسات والمدرسين تستخدم راديو واضحًا وزر تطبيق وGET أصليًا.

متابعة المذاكرة تخص الطالب المسجل فقط، وتقرأ وصوله وتقدمه الحقيقيين. الحساب الجديد يعرض تفعيل الكود، ولا تعرض الرئيسية تقدمًا مصطنعًا للزائر أو الأدمن. إجمالي الدروس والمكتمل يستبعدان الدروس والوحدات المحذوفة في الرئيسية وكورساتي بالطريقة نفسها، دون تعديل سجلات التقدم.

الدارك مود العام محفوظ عبر النظام السابق. ألوان التصميم الجديد تقتصر على الواجهة العامة؛ لوحة الإدارة تحتفظ بتقسيمتها وألوانها. التنقل على الموبايل يتيح الرئيسية والكورسات والمدرسين والتقييمات وكورساتي، والحساب متاح في الهيدر. الحركة انتقالات قصيرة عند التفاعل، مع احترام تقليل الحركة.

## تجهيز الكود للأونلاين

- مفاتيح Supabase الحديثة تستخدم `apikey`، مع الاحتفاظ بدعم JWT القديم وBearer الخاص بالمستخدم.
- اتصال قاعدة البيانات غير المحلي يبدأ بتوصيلة واحدة وTLS مع تحقق الشهادة. لا تغيير في الاتصال المحلي المحروس.
- تخزين الصور يستخدم قرص الجهاز فقط في الوضع المحلي، وStorage خاصة بإعداد صريح للأونلاين. حد الملفات الجديدة 4MiB مع هامش multipart، لتناسب حدود Netlify؛ روابط `/media/images/UUID` الحالية محفوظة. تنظيف الملف الجديد بعد فشل الحفظ best effort؛ لا حذف تلقائي لصور تاريخية.
- `POST /api/internal/deadlines` محمي بسر `APP_JOB_SECRET` مستقل، ويصحح محاولة واحدة باستخدام المنطق الحالي. حد كل SQL statement عشر ثوانٍ، و`maxDuration=30` تلميح للمنصة؛ لا يثبتان زمنًا كليًا أو قدرة معالجة التراكم.
- أضيف `netlify.toml` للبناء عبر `npm run build` ومخرجات `.next`، وNode 22 مع `.nvmrc`. لا أسرار في إعداد البناء.

## ما اتنفذ على Supabase فعلًا

المشروع: `mnsaaa`، المرجع `soggnbfxawlwopglghas`، منطقة `eu-west-1` وPostgres 17.11. تحققت المراجعة قبل التغيير من خلو المشروع من جداول المنصة وغياب دور التطبيق والكتالوج.

طُبقت الملفات التاريخية الأربعة دون تعديلها، بعد الموافقة الصريحة. سجل السحابة يستخدم الإصدارات `20261003220027` و`20261003220036` و`20261003220044` و`20261003220053`. عدد الجداول 33؛ RLS مفعلة على 32، وجدول `runtime_migrations` الخاص لا يملك دور التطبيق صلاحية قراءته. دور التطبيق غير إداري، بلا inheritance أو bypass RLS، والوصول إلى schema ممنوع على `anon` و`authenticated`.

فحص Security Advisors أعاد صفر ملاحظات. فحص الأداء أعاد معلومات عن عشرة مفاتيح أجنبية دون covering index وأربعين index غير مستخدم في قاعدة فارغة؛ لم تُحذف indexes أو تُضاف أخرى بمجرد هذه المعلومات. تحتاج ملاحظات المفاتيح المركبة تقييمًا مع الاستعلامات الفعلية، لأن بعضها يبدأ بمفتاح فريد مفهرس بالفعل. [مرجع فحص المفاتيح الأجنبية](https://supabase.com/docs/guides/database/database-linter?lint=0001_unindexed_foreign_keys).

أضيف الكتالوج التجريبي بمعاملة واحدة محروسة ترفض الكتالوج غير الفارغ، ومعرّفات مولدة داخل قاعدة البيانات. القراءة اللاحقة أكدت 3 صفوف و4 مواد و4 مدرسين و8 كورسات مسودة و12 وحدة و33 درسًا مسودة، دون نشر أو فيديوهات أو حسابات. طريقة التجهيز والبصمات في [دليل كتالوج العرض](../deployment/catalog-seed.ar.md).

## التحقق

نجحت `lint` و`typecheck` و`format:check` والبناء على Node 22.19. شُغلت النسخة المبنية، ونجحت 108 حالات الوظائف المعتادة، و10 إعداد الاتصال/Auth، و11 التخزين، و9 مدخل الجدولة: **138 حالة مستقلة**. أضيف اختبار HTTP فعلي محلي للمدخل بثلاث حالات: رفض الطلب دون سر، رفض سر خاطئ، ونجاح الطلب الصحيح مع SQL فعلي واستجابة عددية خاصة. إجمالي الحالات مع هذا الفحص المحلي 141؛ الجولات المعادة لا تُحسب مرة أخرى.

بعد إضافة معامل timeout للجدولة أُعيدت حالات التعلّم العشرون والتقييمات المستقلة الخمس عشرة بنجاح. لا تتضمن هذه النتائج اتصال التطبيق بـSupabase أو تجربة Netlify فعلية.

في المتصفح: راجعت الرئيسية على 1280px، والموبايل بمحاكاة viewport عند 320 و390 و412px، والفاتح والداكن واستمرار الثيم بين الصفحات. البحث المباشر وعدم وجود نتائج والمسح والصف والمادة وتطبيق فلاتر الكورسات نجحوا. راجعت إنشاء ودخول طالب محلي بلا اشتراكات، ومتابعة حساب اختبار لديه تاريخ وصول فعلي، وكروت كورساتي ولوحة الإدارة. أسماء المدرسين تستخدم Cairo بوزن 800، ولم يظهر تمرير أفقي في الحالات المقاسة. هذه محاكاة عرض داخل متصفح الكمبيوتر؛ Back/Forward وأسهم الراديو لم تُختبر يدويًا في هذه الجولة.

لقطات الحالة وتقاريرها داخل `.local/design-implementation`، وبيانات حسابات الاختبار والأسرار خارج Git. لم تتغير محتويات كورسات المستخدم المسودة بسبب التصميم أو الاختبارات.
