القرارات: [سجل المنتج](../phase-1/decisions.ar.md). الخطة الأصلية: [المراحل 2–8](../phase-1/implementation-backlog.ar.md). المرحلة الأولى مكتملة كمواصفات منتج؛ جودة التصميم النهائية والـprototype لم تُعتمد بصريًا في مراجعة المرحلة الأولى.

توجيه المستخدم الأخير: التركيز على البناء المحلي، وعدم التوسع في اختبارات الحماية حاليًا. تبقى صلاحيات الوظائف وحفظ الأسرار والتاريخ ضمن البناء، وتُؤجل تهيئة حماية الاستضافة والتحقق على الخدمة المستهدفة إلى ما قبل إتاحة المشروع لطلاب حقيقيين. لا يعد هذا قبولًا نهائيًا لـF01 أو شراءً لـSupabase/Vercel. إعداد التجربة المحلية المحمي لم يُزل.

Bunny مزود الفيديو المختار، لكن تشغيلها والدفع مؤجلان حتى مراجعة المشروع العامل والموافقة على التكلفة. أثناء البناء يستخدم ملف فيديو محلي ومزود تجريبي؛ فحص الفيديو الحقيقي مطلوب قبل الإطلاق.

موافقة F02 غطت إعداد حالات المنصة وقواعدها وأمثلتها، ورد سؤال السحب أكد عودة الطالب بكود جديد إذا كان الحساب نشطًا والكورس منشورًا. موافقة المستخدم «ابدء» التالية غطت F03، ثم «تمام اشتغل» غطت F04. موافقة «ابداء» الأخيرة بعد شرح F05 غطت بناء الفرونت وتشغيله والتحقق منه؛ أُنجزت دون ربط بيانات تجارب F01/F03/F04 أو تغيير إعدادها. لا migration منتج أو خدمة سحابية أو تغيير Figma ضمن F03–F05. توجيه المالك التالي يجيز مواصلة دفعات البناء المحلي والتحقق منها دون انتظار موافقة منفصلة؛ القرارات المهمة الجديدة فقط ترجع إليه.


تحديث 2026-10-03: انتقلت المنصة من واجهة F05 إلى تطبيق محلي عامل. أضيفت migration المنتج وبيانات تجريبية وجلسات الخادم وعمليات الأدمن والطالب. نتائج F01–F05 السابقة أدلة تاريخية تخص تجاربها؛ التقرير الجديد يحدد فحوص التطبيق الحالي وحدوده. ربط Bunny والتكلفة والاستضافة والتحقق قبل الإطلاق ما زال مؤجلًا.
