# معايير قبول قابلة للاختبار

معايير مواصفات جاهزة للتنفيذ، وليست اختبارات منفذة. مرتبطة بـ[القرارات](decisions.ar.md)؛ السلوك الأساسي معتمد، والتفاصيل الموسومة كمقترح في السجل تُراجع تقنيًا قبل تنفيذ المرحلة المعنية. بيئة الاختبار تحتاج طالبين وأدمن وكورس مسودة ومنشور وأكواد بحالات مختلفة وساعة خادم قابلة للمحاكاة.

| المعرّف / القرار | السيناريو والنتيجة المتوقعة |
|---|---|
| AC01 D01/D03/D24 | طالب يسجل باسم وصف وموبايل وكلمة سر، ويدخل بالموبايل وكلمة سر؛ الناقص والخاطئ يفسران قرب الحقل والتكرار لا ينشئ هوية ثانية. الأدمن يستعيد الحساب بعد تحقق حضوري مسجل؛ معرفة الرقم أو الكود وحدها لا تكفي. السر/الرابط المؤقت يستخدم مرة واحدة ويطلب تغيير كلمة السر؛ سر منتهي لا يغيرها |
| AC02 D01/D18 | طالب يطلب مسار/عملية أدمن مباشرة أو بيانات طالب آخر: رفض من الخادم، لا إخفاء زر فقط. حساب معطل لا يبدأ مشاهدة أو تفعيل أو محاولة ولا يرسل إجابات جديدة؛ التاريخ محفوظ، وموعد نهاية الاشتراك لا يتغير بالتعطيل أو إعادة التفعيل؛ تمديد التعويض عملية أدمن مستقلة مسجلة |
| AC03 D09/D23 | طالب يكتشف مدرسًا وكورسًا حسب الصف والمادة؛ يرجع للقائمة مع نفس الفلاتر. غير المشترك يرى بيانات المنهج فقط ولا يحصل على رابط تشغيل أو أسئلة محمية بتغيير URL |
| AC04 D04/D06 | كود صالح لكورس A ينشئ وصولًا لـA وحده. كود لـB لا يفتح A ولا يُستهلك بصمت؛ يظهر اسم الكورس الصحيح قبل تأكيد التفعيل. الكود الخاطئ/الملغى/المنتهي يترك المدخل قابلًا للتصحيح ولا ينشئ وصولًا |
| AC05 D04/D06 | طالبان يفعّلان نفس الكود بالتزامن: نجاح واحد فقط، مالك واحد ووصول واحد. إعادة نفس الطلب أو فقد رد النجاح ثم المحاولة لا تمدد المدة ولا تنتج اشتراكًا مكررًا |
| AC06 D04 | تفعيل 2026-10-02 12:00 UTC لمدة 30 يومًا ينتهي 2026-11-01 12:00 UTC؛ يسمح قبل النهاية ويمنع عندها. العرض بتوقيت القاهرة؛ الحساب بالوقت المطلق دون تغيير مدة عند تغير الساعة المحلية. تختبر أيضًا 60 و90 يومًا وحدود نهاية الشهر |
| AC07 D06 | الكود دون آخر موعد يقبل حتى الاستخدام أو الإلغاء ما دام الكورس منشورًا. إن حدد موعد T: الطلب قبل T يقبل، عند T وبعده يرفض وفق تفصيل الوقت الحصري المقترح. وصول بدأ قبل آخر التفعيل يستمر حتى نهايته؛ صلاحية الكود ليست نهاية الاشتراك |
| AC08 D07 | انتهاء وصول الطالب T ومستمر حاليًا؛ تجديد 30 يومًا يبدأ من T. لو منتهي يبدأ الآن. تجديدان متزامنان بكودين مختلفين يحسبان المدد دون فقد تحديث؛ التقدم والنتائج يبقيان |
| AC09 D08/D18 | إلغاء غير المستخدم يمنع تفعيله؛ إلغاء متزامن مع التفعيل له نتيجة واحدة متسقة لا كود مستخدم بلا وصول. المستخدم لا يعود للبيع؛ سحب الوصول/تمديده يحتاج إذن أدمن وسبب ويسجل الأثر |
| AC10 D09/D10 | اشتراك ينتهي أثناء التصفح: أي طلب جديد محمي يرفض مع تجديد واضح. الكورس المنتهي يبقى في كورساتي والتاريخ محفوظ. الفيديو لا يجدّد رابطًا بعد الانتهاء؛ اختبار مدة الرابط الحالية وفق السياسة المعتمدة |
| AC11 D05/D12 | قبل النجاح، الرابط المباشر للدرس التالي يرفض مع السبب. 69% لا يفتح و70% يفتح دون تقريب درجة أقل إلى النجاح؛ مسودة أو تسليم دون نجاح لا يفتح. إعادة الواجب متاحة بلا حد. وفق تفصيل التنفيذ المقترح: لا تسليم نهائي بإجابات ناقصة، والنجاح مرة يثبت الفتح رغم فشل محاولة لاحقة. تجاوز الأدمن مسجل وللطالب والدرس المقصودين فقط |
| AC12 D11/D25 | زر «خلصت الدرس» لدرس متاح يحسب إكماله مرة واحدة، دون فتح التالي قبل نجاح الواجب؛ تكرار الطلب لا يعد الدرس مرتين. حفظ الموضع لا يغير الإكمال. حذف أو إعادة ترتيب درس استُخدم ممنوع؛ تعديل عنوانه لا يمس التقدم. إضافة درس في النهاية تحافظ على إكمال الدروس السابقة؛ مقام النسبة الحالي وفق التفصيل المقترح في سجل القرارات |
| AC13 D13 | الامتحان المنشور له أسئلة باثنين إلى ستة اختيارات وصحيح واحد ودرجات موجبة؛ لا محاولة جديدة بعد حد المحاولات أو خارج نافذة معتمدة. طالب بلا وصول لا يبدأ؛ قبل البدء يرى المدة والمحاولات وسياسة النموذج والانتهاء |
| AC14 D13/D15/D25 | تحديث الصفحة أو جهاز آخر يستأنف نفس المحاولة والموعد وإصدار الأسئلة الذي بدأت به؛ لا محاولة ثانية فعالة لنفس التقييم/الطالب. تعديل الامتحان أثناء المحاولة لا يغير أسئلتها أو درجاتها. تغيير ساعة الجهاز لا يزيد الوقت. حفظان متزامنان لإجابة يعتمدان الإصدار الأحدث المؤكد ولا يستبدله طلب قديم |
| AC15 D15 | قطع الشبكة: يظهر «على الجهاز فقط» دون «تم الحفظ»؛ عند العودة قبل الموعد تزامن الإجابات. عند الموعد يسلم آخر محفوظ بالخادم؛ الإجابات المحلية المتأخرة لا تُقبل. التطبيق المغلق لا يمنع إنهاء المحاولة بالخادم |
| AC16 D15 | تسليم يدوي بالتزامن مع التسليم التلقائي أو إعادة الطلب: نتيجة نهائية واحدة ومجموع واحد. الطلب بعد التسليم لا يعدّل الإجابات؛ فقد رد التسليم يمكن استرجاع نتيجته |
| AC17 D10 | اشتراك ينتهي أثناء محاولة بدأت بوصول ساري: تكمل المحاولة حتى موعدها الأصلي فقط؛ لا محاولة جديدة ولا مشاهدة جديدة. استئناف نفس المحاولة قبل موعدها لا يتطلب تمديد الاشتراك |
| AC18 D09/D14/D17 | قبل موعد نموذج الإجابة لا يعيده API ولا بيانات الصفحة. عند الموعد يرى الطالب نتيجته السابقة ونموذجها حتى لو انتهى اشتراكه، دون السماح بمحاولة جديدة؛ الصحيح والخطأ وغير المجاب من إصدار المحاولة، دون كشف إصدار جديد |
| AC19 D01/D26 | أدمن ينشئ مدرسًا وكورسًا ووحدة ودرسًا وواجبًا وامتحانًا؛ المسودة لا تظهر ولا تقبل كود تفعيل. نقص فيديو جاهز لدرس منشور أو تقييم صالح يمنع النشر مع قائمة إصلاح؛ النجاح يجعل الكورس قابلًا للاكتشاف والتفعيل. بعد النشر إضافة حصة جاهزة في النهاية متاحة، ومسودة درس جديد لا تدخل قائمة الطالب أو تقدمه |
| AC20 D16/D17/D25/D26 | أرشفة تخفي الكورس وتمنع تفعيلًا جديدًا دون استهلاك الكود وتبقي الوصول السابق حتى نهايته. تعديل امتحان مستخدم ينشئ إصدارًا جديدًا دون تغيير أسئلة أو درجات المحاولات السابقة أو الجارية. فيديو فشل في المعالجة لا يصبح جاهزًا للنشر؛ إعادة المعالجة لا تكرر الدرس |
| AC21 D06/D18 | توليد العدد المطلوب يعطي أكوادًا فريدة مرتبطة بالكورس والمدة؛ تكرار طلب التوليد لا ينشئ دفعتين بصمت. CSV يطابق الدفعة ومتاح للأدمن فقط؛ النصوص لا تُنفذ كصيغ جداول. سجل الطالب يخفي الكود الكامل |
| AC22 D19 | الدخول من جهاز آخر مسموح؛ فتح فيديو عليه ينقل جلسة المشاهدة ويمنع الجلسة القديمة من طلب تشغيل/تجديد رابط، برسالة واضحة. فقد النبض لا يترك قفلًا دائمًا. رابط منتهي أو طالب مختلف لا يحصل على إصدار جديد. يختبر حد استمرار ما سبق تحميله وفق صلاحية الرابط؛ أي تقييد نطاق يختبر عند اختيار المزود |
| AC23 D22/G12 | الرحلات الأساسية تعمل على المقاسات المحددة، 200% نص وهاتف أفقي دون فقد زر أو تمرير أفقي أساسي؛ حقل الكود LTR داخل RTL؛ keyboard وfocus وحوار يعيد التركيز، labels ورسائل حفظ مقروءة؛ التباين و48px لمس يراجعان فعليًا |
| AC24 D01/D02/D05/D12 | اختبار نجاح شامل: أدمن ينشر كورسًا ويولد كودًا؛ طالب جديد يسجل ويفعّل ويشاهد ويعلم الدرس مكتملًا وينجح في الواجب بـ70% أو أكثر ويفتح التالي ويحل الامتحان ويرى النتيجة والنموذج وفق موعده؛ يجدد أو تنتهي صلاحيته وفق القاعدة المعتمدة |
| AC25 D27 | أثناء التطوير تعمل الرحلة بملف فيديو تجريبي محلي وواجهة مزود محاكية دون حساب Bunny أو مفاتيح أو طلبات إليها. المحاكاة وحالة البيئة ظاهرة للمراجع، ولا تنتقل لبيئة الإنتاج ولا تسمح بنشر محتوى محاكى للبيع. بعد مراجعة المشروع واعتماد التكلفة يربط Bunny ويعاد AC19/20/22/24 بفيديو حقيقي، مع فحص تشغيل الهاتف والجودات والحفظ والتوكنات والنطاق والانتهاء وتكلفة الاستخدام قبل الإطلاق |
| AC26 D28/D04/D08 | طالب سُحب وصوله لكورس يستطيع تفعيل كود جديد صالح لنفس الكورس إذا كان حسابه نشطًا والكورس منشورًا. ينشأ تفعيل جديد بمالك واحد؛ الكود القديم المستخدم لا يزيل السحب أو يزيد المدة، وتبقى المنحة المسحوبة والتقدم والنتائج في التاريخ. الحساب المعطل أو الكورس المؤرشف أو كود طالب آخر يمنع العودة بلا استهلاك للكود الجديد. بدء المدة الجديدة من وقت التفعيل اختيار التنفيذ الموضح في F02 |

بوابة الاعتماد: لا يُستبدل الاختبار بالخادم بانتقال prototype ثابت. تقاس الصلاحيات والتزامن والوقت من الخادم، ثم تُفحص رسائل الواجهة. فشل AC05/09/16/18/19 يمنع إطلاق البيع أو التقييم حتى الإصلاح.

فصل أدلة الفيديو وفق D27: AC24 قبل الاشتراك يثبت منطق التطبيق مع فيديو اختبار، ولا يثبت تحويل الجودات أو شبكة Bunny أو حمايتها. اجتياز AC25 بعد الربط شرط مستقل للإطلاق الحقيقي.
